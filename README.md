# KotlinTelegramBot

**KotlinTelegramBot** — учебный Telegram-бот для изучения английских слов, разработанный на языке **Kotlin**.  
Проект помогает закрепить знания Kotlin, научиться работать с Telegram Bot API, базой данных и пользовательским прогрессом.

---

## 📚 Основные возможности

- Изучение английских слов в формате теста
- Выбор перевода с помощью кнопок
- Изображения-подсказки для слов
- Подсчёт выученных слов
- Отображение прогресса в процентах
- Персональный прогресс для каждого пользователя
- Сохранение данных после перезапуска бота
- Сброс прогресса обучения
- Отмена последнего правильного ответа
- Загрузка собственного словаря

Слово считается выученным после трёх правильных ответов.

---

## 🤖 Команды бота

- `/start` — открыть главное меню
- `/reset` — сбросить прогресс
- `/undo` — отменить последний правильный ответ

---

## 🧠 Формат обучения

Бот показывает пользователю английское слово и предлагает несколько вариантов перевода.

После выбора ответа бот:

- проверяет правильность ответа;
- сообщает результат;
- сохраняет прогресс пользователя;
- показывает следующий вопрос;
- отображает статистику обучения.

---

## 📄 Формат словаря

Каждое слово записывается с новой строки в следующем формате:

```text
english word|перевод
```

Пример:

```text
hello|привет
friend|друг
work|работа
```

Пользователь также может отправить боту собственный файл со словами.
